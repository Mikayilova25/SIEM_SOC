## Start and stop the lab (D2)
**Start (in this order)**
1. Start VM `siem-host`, wait until it has booted.
2. `cd ~/wazuh-docker/single-node && docker compose up -d`
3. `docker ps` - three containers must be `Up` (indexer may take 1-2 minutes).
4. Start `ubuntu-web`, then `win-client`.
5. Open `https://10.10.10.10` on the Dell and check both agents are Active.

**Stop**
1. Shut down `win-client` and `ubuntu-web`.
2. On siem-host: `docker compose stop` (never `docker compose down -v`: `-v` deletes the data volumes).
3. `sudo poweroff` siem-host.

## Path of one event (V2)
Example: the failed SSH login on ubuntu-web.
1. `sshd` on ubuntu-web writes "Failed password for invalid user fakeuser" to the system journal.
2. The Wazuh agent (agent 001) reads the journal (`location: journald`) and sends the line over TCP 1514 to the manager at 10.10.10.10, encrypted. (Enrolment used port 1515 once.)
3. The manager's analysis engine decodes the line (decoder `sshd`: extracts `srcip`, `srcuser`) and matches rule 5710, giving it a level and MITRE tags.
4. The manager writes the alert to its alert log and ships it to the indexer.
5. The indexer stores it in the `wazuh-alerts-4.x-*` index.
6. The dashboard queries the indexer and shows the alert in Discover and Threat Hunting.

```
endpoint log -> agent -> (1514) -> manager: decode + rules -> indexer -> dashboard -> analyst
```
Windows works the same way, except the agent reads the Windows event channel instead of a log file, and Sysmon adds the Process Create events (command line, parent process, hashes) that the default Windows logs lack.

## SIEM, EDR, XDR and where Wazuh fits
- SIEM: collects logs from many sources, correlates them and raises alerts.
- EDR: agent on the endpoint that watches processes, files and behaviour, and can respond.
- XDR: extends detection and response across endpoints, network, cloud and more.
- Wazuh combines SIEM and endpoint-agent features (log analysis, file integrity, vulnerability detection, active response) and is often described as an open-source XDR/SIEM platform.
